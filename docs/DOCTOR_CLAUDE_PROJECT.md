# مشروع Claude للدكتور — "شيتات المحاضرات"
### Ready-made Claude project that turns any material into MN sheets

هذا الملف لك أنت (من يجهّز المشروع ويسلّمه للدكتور). كل ما يحتاجه المشروع موجود في مجلد واحد: **`docs/doctor-project/`** (9 ملفات).

> يُعاد توليد المجلد تلقائياً بعد أي تحديث للصيغة أو الأمثلة: `node scripts/doctor-project.mjs` (Claude يشغّله بنفسه). ملف التعليمات `INSTRUCTIONS.md` يُكتب يدوياً.

---

## 1. ماذا يفعل المشروع؟
يأخذ **أي شيء** يرسله الدكتور ويحوّله إلى ملف `.mn` كامل جاهز للرفع على الموقع:
- ملف PDF أو Word أو شرائح PowerPoint، صور أو مسح لدفتره، شيت قديم، نص ملصوق، عناوين فقط، أو اسم موضوع.
- **عدة محاضرات معاً** مع كلمة واحدة مثل "صيغهم" ← ملف كامل لكل محاضرة.
- أوامر على ملف موجود: "أضف رسمة"، "أضف 3 أمثلة"، "قسّمه لمحاضرتين"، "اجعل الحلول خطوة بخطوة"، أو رسالة خطأ من الموقع.

**ثلاث قواعد ثابتة في التعليمات (تحديث 2026-11-01):**
- **كل شيت بالعربية والإنجليزية دائماً** (`lang: both`) دون أن يحدد الدكتور، ويترجم Claude المادة بنفسه. لغة واحدة فقط إذا طلبها الدكتور صراحةً لشيت معيّن.
- **يتعامل مع الدكتور ببساطة:** أستاذ رياضيات، لا مطوّر موقع. لا مصطلحات تقنية، لا يطلب منه تعديل كود، يتذكر ما قاله سابقاً.
- **مبادر:** بعد كل تسليم يقترح 2–3 أفكار لتحسين المحاضرة ويسأل سؤالاً أو اثنين، ويبحث عن الإجابات الناقصة بنفسه (يحل الأمثلة، يكمل البراهين، يتحقق من المراجع) بدل أن ينتظر الأوامر.

ويلتزم بأن يستخدم **كل عناصر اللغة المناسبة للمحتوى**: كل أنواع الصناديق، الحلول خطوة بخطوة، عمليات الصفوف، المعادلات المرقّمة، الجداول والأعمدة، أسئلة الاختيار، و3 رسومات على الأقل في كل محاضرة (بايثون + رسومات الموقع المتحركة).

## 2. إنشاء المشروع (مرة واحدة، من حساب الدكتور أو حسابك ثم مشاركته)
1. claude.ai ← **Projects** ← **Create project**.
2. **Name:** `شيتات المحاضرات — Lecture Sheets`
3. **Description:** `يحوّل أي مادة محاضرة إلى ملف .mn جاهز للرفع على ahmadelajou.com`
4. **Instructions:** افتح `docs/doctor-project/INSTRUCTIONS.md`، انسخ محتواه **كله**، والصقه في خانة Project instructions.
5. **Project knowledge:** ارفع الملفات التسعة الباقية من نفس المجلد:

| الملف | ما هو |
|---|---|
| `MN_SYNTAX_SPEC.md` | قواعد الصيغة كاملة (v1.4) — **أهم ملف** |
| `EXAMPLE-complete-sheet.txt` | محاضرة واحدة فيها **كل** العناصر و19 رسمة — النموذج الرئيسي |
| `EXAMPLE-lecture-01.txt` | شيت مطابق لشيت الدكتور الأصلي (أسلوبه ورموزه) |
| `EXAMPLE-python-figures.txt` | رسومات بايثون صحيحة |
| `EXAMPLE-builtin-figures.txt` | كل رسومات الموقع المتحركة والتفاعلية |
| `EXAMPLE-arabic-sheet.txt` | شيت بالعربية |
| `EXAMPLE-bilingual-sheet.txt` | شيت واحد بلغتين (عربي + إنجليزي) يتبع لغة الموقع |
| `EXAMPLE-lecture-04.txt` | قيم ذاتية ومستوى طور |
| `DOCTOR_GUIDE.md` | دليل الموقع، ليجيب عن أسئلة الدكتور |

الأمثلة بامتداد `.txt` عمداً: Claude يقبل رفع ملفات `.txt` دائماً، بينما قد يرفض امتداد `.mn`. المحتوى هو نفسه.

6. (اختياري) ارفع أيضاً ملفات PDF لشيتات الدكتور القديمة، كمرجع إضافي لأسلوبه.
7. إن أنشأته من حسابك: **Share** ← أضف إيميل الدكتور.

## 3. طريقة الاستخدام (للدكتور)
| يكتب الدكتور | ماذا يحدث |
|---|---|
| يرفع 4 ملفات PDF ويكتب *"صيغهم"* | 4 ملفات (`lecture-01.mn` … `lecture-04.mn`) بالعربية والإنجليزية + اقتراحات وأسئلة |
| *"حوّل هذا الملف إلى شيت المحاضرة 3"* + إرفاق PDF | ملف `lecture-03.mn` كامل |
| *"اكتب محاضرة عن تحويل لابلاس للمشتقة الكسرية، 75 دقيقة"* | محاضرة كاملة بأمثلة ورسومات وأسئلة |
| يرسل صور دفتره | يقرأ الخط ويحوّله لشيت |
| *"أضف رسمة توضح الحلول لقيم ألفا مختلفة"* | يعيد الملف كاملاً ومعه الرسمة |
| يلصق رسالة الخطأ من الموقع | يعيد الملف مصحّحاً ويشرح الخطأ بسطر |
| *"كيف أوافق على طالب؟"* | يجيب من دليل الموقع |

بعدها في الموقع: لوحة التحكم ← المساق ← المحاضرة ← **Upload .mn** (أو لصق النص في المحرر) ← **Preview** ← **Save**.

## 4. متى أحدّث المشروع؟
عند أي تحديث لصيغة MN أو الأمثلة: يعيد Claude توليد `docs/doctor-project/`، فتستبدل الملفات في مشروع الدكتور بالنسخ الجديدة. وإن تغيّر `INSTRUCTIONS.md` تلصقه من جديد. آخر تحديث للحزمة: **2026-11-01 (تعليمات جديدة: لغتان دائماً، تعامل بسيط، مبادرة، عدة محاضرات معاً)**. ما يجب تحديثه في مشروع الدكتور: لصق `INSTRUCTIONS.md` من جديد، استبدال `MN_SYNTAX_SPEC.md` و `DOCTOR_GUIDE.md`، ورفع `EXAMPLE-bilingual-sheet.txt`. الحزمة كاملة جاهزة أيضاً كملف مضغوط `doctor-claude-project.zip`.
