## Phase portraits ($\X'=A\X$)

::: theorem "Distinct real eigenvalues" {#thm:distinct}
If the $n\times n$ matrix $\A$ has $n$ distinct real eigenvalues $\lambda_1,\dots,\lambda_n$ with eigenvectors $\K_1,\dots,\K_n$, then the general solution is
$$\X=c_1\K_1e^{\lambda_1t}+c_2\K_2e^{\lambda_2t}+\cdots+c_n\K_ne^{\lambda_nt}.$$
:::

::: keybox
$\X=\K e^{\lambda t}$ solves $\X'=\A\X$ !!if and only if!! $\lambda$ is an eigenvalue of $\A$ and $\K$ a corresponding eigenvector.
:::

::: example "Saddle point" {#ex:saddle}
Sketch the phase portrait of $\dfrac{dx}{dt}=2x+3y,\ \dfrac{dy}{dt}=2x+y$.
:::

::: solution steps
$|\A-\lambda I|=\lambda^2-3\lambda-4=(\lambda-4)(\lambda+1)$, so $\lambda_1=4,\ \lambda_2=-1$.
>>>
$\K_1=(3,2)^T,\ \K_2=(1,-1)^T$ and $\X=c_1\begin{pmatrix}3\\2\end{pmatrix}e^{4t}+c_2\begin{pmatrix}1\\-1\end{pmatrix}e^{-t}$.
>>>
```field x=[-4,4] y=[-4,4] caption="Saddle: trajectories follow the eigenlines"
matrix [2 3; 2 1]
trajectories from (1,0.2) (-1,-0.2) (0.2,1) (-0.2,-1) (2,-2.2) (-2,2.2) (3,-2) (-3,2)
eigenlines on
classify on
flow on
```
:::

```field x=[-3,3] y=[-3,3] caption="Stable spiral $\X'=\begin{pmatrix}-0.3&-1\\1&-0.3\end{pmatrix}\X$"
system x' = -0.3x - y ; y' = x - 0.3y
trajectories from (2.5,0) (-2.5,0)
classify on
```

```field x=[-3,3] y=[-3,3] caption="Slope field of $y'=x-y$"

```

::: caution
Never write $\K=\mathbf 0$: the zero vector is **never** an eigenvector.
:::
