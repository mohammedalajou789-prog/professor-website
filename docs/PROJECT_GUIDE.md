## 1. طريقة العمل بيننا
1. في بداية كل جلسة جديدة يرفع المستخدم الكود (البيئة السحابية لـ Claude تُمسح بين الجلسات). أمر التغليف (PowerShell):
   ```powershell
   cd "C:\Users\mohammed alajou\professor-website"
   tar -a -cf "$env:USERPROFILE\Desktop\site.zip" --exclude=node_modules --exclude=.next --exclude=.git --exclude=".env*" .
   ```
   - **إن كانت المحادثة مربوطة بالحاسوب (تطبيق Claude desktop):** Claude يقرأ ويكتب مجلد `professor-website` مباشرة، فلا حاجة للضغط والفك.
2. Claude يعدّل، ويبني (`npm run build`)، ويلتقط صوراً للصفحات على الهاتف والحاسوب قبل التسليم.
3. التسليم = **zip** + `CHANGES.md` (خطوات مرقّمة: أوامر PowerShell، SQL، إعدادات، قائمة اختبار).
   - التحديثات الكبيرة: المشروع كاملاً. ويُحذف `src` قبل الفك لأن الهيكل تغيّر.
   - التحديثات الصغيرة: الملفات المعدلة فقط.
4. ملفات SQL مرقّمة (`sql/00N_….sql`) وتُنفّذ بالترتيب في Supabase → SQL Editor. كلها آمنة لإعادة التشغيل.
5. لا أسرار في المحادثة أو الملفات. مكانها `.env.local` و Vercel فقط.
