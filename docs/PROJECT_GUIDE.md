> يحدّثه Claude تلقائياً بعد كل خطوة. آخر تحديث: 2026-11-03 (التحديث 9: مساقات مفتوحة، ترتيب بالسحب، العرض بلا إنترنت، PDF المحلولة للدكتور، أبحاث جارية، لوحة أدمن جديدة)

## 1. طريقة العمل بيننا
1. في بداية كل جلسة جديدة يرفع المستخدم الكود (البيئة السحابية لـ Claude تُمسح بين الجلسات). أمر التغليف (PowerShell):
   ```powershell
   cd "C:\Users\mohammed alajou\professor-website"
   tar -a -cf "$env:USERPROFILE\Desktop\site.zip" --exclude=node_modules --exclude=.next --exclude=.git --exclude=".env*" .
   ```
   - **إن كانت المحادثة مربوطة بالحاسوب (تطبيق Claude desktop):** Claude يقرأ ويكتب مجلد `professor-website` مباشرة، فلا حاجة للضغط والفك.
   - **أسرع طريقة (التحديث 9):** المستودع عام، فـ Claude ينسخه من GitHub (`git clone`) إلى بيئته، ويقارن تواريخ ملفات الجهاز بآخر commit، ثم يكتب الملفات المعدّلة فقط إلى الجهاز.
2. Claude يعدّل، ويبني (`npm run build`)، ويلتقط صوراً للصفحات على الهاتف والحاسوب قبل التسليم.
   - **بيانات تجريبية للصور:** خادم Supabase مزيّف صغير (Node، منفذ 54321) يردّ على `/rest/v1/<table>` ببيانات ثابتة، و `NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:54321`. لوحة الأدمن: `MOCK_DATA=1 ADMIN_PREVIEW=1` (+ `NEXT_PUBLIC_ADMIN_PREVIEW=1` وقت البناء). الشيتات: مفتاح `sample:<name>` يُقرأ من `SAMPLES` عند `MOCK_DATA=1` أو `MN_DEMO_PUBLIC=1`. أدوات التجربة في بيئة Claude فقط، ليست في المستودع.
3. التسليم = **zip** + `CHANGES.md` (خطوات مرقّمة: أوامر PowerShell، SQL، إعدادات، قائمة اختبار).
   - التحديثات الكبيرة: المشروع كاملاً. ويُحذف `src` قبل الفك لأن الهيكل تغيّر.
   - التحديثات الصغيرة: الملفات المعدلة فقط.
4. ملفات SQL مرقّمة (`sql/00N_….sql`) وتُنفّذ بالترتيب في Supabase → SQL Editor. كلها آمنة لإعادة التشغيل.
5. لا أسرار في المحادثة أو الملفات. مكانها `.env.local` و Vercel فقط.
6. **GitHub:** المستودع `mohammedalajou789-prog/professor-website` (فرع `main`). الرفع بأمر واحد يتأكد أولاً أن `.env.local` غير مرفوع:
   ```powershell
   git add -A
   if (git diff --cached --name-only | Select-String '\.env\.local') { Write-Host "STOP" -ForegroundColor Red; git reset -q } else { git commit -m "رسالة"; git push origin main }
   ```
   تنبيهات `LF will be replaced by CRLF` طبيعية على Windows. آخر رفع: إصلاح عرض الشيت على الهاتف (2026-11-01). التحديث 9 كُتب في المجلد (2026-11-03) وينتظر أمر الرفع.
   - **المستخدم لا يعدّل أي شيء يدوياً:** Claude يكتب الملفات مباشرة في المجلد (عند ربط المحادثة بالحاسوب) ويعطي أمراً واحداً للصق: الرفع إلى GitHub ثم `npm run dev`. Vercel ينشر تلقائياً بعد الرفع خلال دقيقة أو دقيقتين.
   - إن لم يكن على الحاسوب shell (device_bash غير متاح): Claude يقرأ الملفات بـ stage ويكتبها بـ commit، ويبني ويختبر في بيئته السحابية. **commit لا يحذف ملفات**: الحذف يكون داخل أمر PowerShell (`Remove-Item`).
   - متصفح تطبيق Claude (Built-in browser) على جهاز المستخدم يصل للموقع الحقيقي؛ بيئة Claude السحابية لا تصل إلى ahmadelajou.com ولا Supabase مباشرة.
7. إن ظهرت 404 لكل الصفحات في `npm run dev` بعد تحديث: ملفات `.next` قديمة → `Remove-Item -Recurse -Force .next; npm run dev`.
